# Bookstore-Analytics-
It is a data analytics and data visualization project design to analyze the bookstore sale , customer behavior . 

The project uses SQL Server to store and manage bookstore data, Python and Pandas for data processing and analysis, and Streamlit with Plotly to create an interactive and user-friendly dashboard.

The dashboard provides important information such as total sales, total revenue, best-selling books, popular genres, customer purchasing patterns, monthly sales trends, and inventory status.
